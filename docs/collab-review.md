# 유사 서비스에서 가져올 요소와 두 번째 버전 "Commute Talk" (2026-10-16)

`docs/launch-review.md`의 경쟁 서비스 조사를 바탕으로, (1) 실제로 손잡을 수 있는 상대가 있는지, (2) 기능 중 우리 앱에 합칠 만한 요소가 무엇인지 정리하고, (3) 그 요소를 합친 다른 버전을 만들었습니다.

## 1. 실제 협업(제휴) 가능성

솔직한 결론: **개인용 웹앱 단계에서 정식 제휴는 현실적이지 않습니다.** 스픽·Pimsleur·ELSA·Loora 같은 회사는 사용자 수와 법인이 있어야 대화가 됩니다. 대신 "허락 없이도 쓸 수 있는 결합"이 있습니다.

| 상대 | 할 수 있는 것 | 비고 |
|---|---|---|
| **Anthropic / Google (API)** | 이미 하고 있음. 사용자 키로 Claude·Gemini를 대화 상대로 씀 | 유일하게 실제로 연결된 "협업" |
| **ChatGPT CarPlay / Gemini Live** | 경쟁자이자 보완재. 우리 앱의 "오늘의 문장"을 ChatGPT에 붙여 넣어 쓰는 프롬프트를 제공할 수 있음 | 차 안 경험은 저쪽이 더 좋음. 복습·기록은 우리가 담당 |
| **Language Transfer** | 무료·오픈소스 오디오 강좌. 링크로 소개하거나, 같은 "소리 내어 말하기" 철학을 설명에 인용 | 콘텐츠 재사용은 라이선스 확인 필요 (CC 계열) |
| **Apple (iOS 음성)** | 프리미엄 음성 안내는 이미 넣음. Siri 단축어·CarPlay는 네이티브 앱이어야 함 | launch-review 4장 1번 |
| **스픽·링글 등 한국 서비스** | 제휴 대상이 아니라 벤치마크 | 우리 강점은 "운전 중·내 문장·무료"라 포지션이 다름 |

## 3. Commute Talk: 다른 버전의 설계

**한 줄:** 수업(Commute Coach)이 "정해진 문장을 외우는 반복"이라면, Commute Talk는 "내 말로 대화하다가 틀린 곳만 한 문장씩 주워 담는 연습"입니다. 두 버전은 **같은 기록**을 씁니다.

**흐름** (`talk.html`)
1. 장면을 하나 누름 (오늘 하루 · 점심 약속 · 주말 · 아침 업무 공유 · 여행). 그 뒤는 모두 음성.
2. 선생님이 장면의 첫 질문을 함. 나는 영어로 답함. 막히면 한국어로 답해도 됨.
3. AI가 JSON으로 `{reply, better, ko, note}`를 돌려줌.
   - `better`: 내 말에 분명한 오류가 있을 때만 자연스러운 한 문장(12단어 이하). 한국어로 답했으면 영어 문장.
   - `reply`: 짧은 반응 + 질문 1개 (마지막 턴은 질문 없이 마무리).
4. `better`가 있으면 "Here's a natural way to say it: …" → 따라 말함 → **규칙(`judge`)으로 판정**, 최대 2회. 틀리면 교정 2개까지만.
5. 일반 8턴, 운전 모드 5턴. 명령(again·meaning·skip·pause·resume·stop) 그대로.
6. 끝나면 돌려받은 문장 최대 3개가 `내 문장`(provenance `teacher_suggested`)으로 저장되어 Commute Coach의 복습에 들어감. 맞게 따라 말했으면 내일 복습, 아니면 오늘 다지기.

**지켜 온 원칙과의 관계**
- 수업 중 음성만: 유지 (장면 버튼 1번).
- 판정은 규칙 기반: 유지. AI는 "고쳐 말한 문장"을 제안만 하고, 그것을 내가 맞게 말했는지는 규칙이 판정. 점수 없음.
- 교정 최대 2개: AI 리캐스트 1개 + 따라 말하기 교정 ≤2개.
- 학습자 발화와 교사 예문 분리: 내 말은 `attempts(kind:'talk')`, AI 문장은 `custom(provenance:'teacher_suggested')`.
- 키는 코드에 없음: Commute Coach에 넣은 키를 같은 localStorage에서 읽음.

**비용 감각**: 턴마다 AI 호출 1번. Gemini Flash면 한 대화(8턴)에 수 원, Claude면 수십 원 수준.

**검증**: 로직 테스트 29개, e2e(가짜 AI 서버: 한국어 답 → 영어 문장 → 시제 틀림 → 교정 → 통과 → skip → stop → 기록 탭에 "내 문장" 표시 → 키 없으면 장면 버튼 비활성).

## 4. 사람이 정할 것

1. **홈 화면에서 Talk를 어떻게 보여 줄지**: 지금은 Commute Coach 시작 버튼 아래 링크 1줄. 탭으로 합칠지, 별도 앱 느낌을 유지할지.
2. **장면 추가·수정**: `core.js`의 `SCENES`에 5개. 본인 생활에 맞는 장면(예: 헬스장, 부모님 방문, 교토 여행)으로 바꾸거나 늘릴지. 회화 샘플 17개 주제를 장면으로 쓸 수도 있음.
3. **턴 수**: 일반 8 / 운전 5가 적당한지 실제로 써 보고 조정.
4. **AI 리캐스트의 품질**: 실제 키로 10번쯤 대화해 보고, 고치지 않아도 될 말을 고치거나(과교정) 틀린 것을 넘기는 경우가 얼마나 있는지 확인. 프롬프트는 `talkPrompt`.
5. **ChatGPT CarPlay와의 역할 분담**: 차 안에서는 ChatGPT에 우리 문장을 들고 가서 쓰고, 복습은 우리 앱에서 하는 "보완 사용법"을 안내할지.
