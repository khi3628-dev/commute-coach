# 출시 점검 보고서 (2026-10-16)

Commute Coach를 "다른 사람도 쓰는 서비스로 출시한다"고 가정하고, 비슷한 서비스와 비교해 부족한 점을 정리했습니다.
- **1~2장**: 비슷한 서비스와의 비교
- **3장**: 이번에 바로 고친 것. 무료이고 코드만 바꾸면 되는 것들입니다.
- **4장**: 사람이 정해야 하는 것. 돈, 법, 방향에 관한 결정이라 손대지 않았습니다.
- **5장**: 실제 iPhone에서 확인할 것

가격과 기능은 2026년 10월 웹 검색 결과입니다. 리뷰·가격 비교 사이트 같은 2차 출처가 많아 대략적인 값으로 보세요.

## 2. Commute Coach의 위치

**강점 (다른 서비스에 없는 조합)**
- **운전 중에 말로 하는 구조화된 수업.** Pimsleur는 정해진 오디오라 내 말을 알아듣지 못합니다. ChatGPT CarPlay는 알아듣지만 커리큘럼과 복습이 없습니다.
- **내 일상 문장으로 하는 간격 반복 복습.** 가장 비슷한 스픽의 '나만의 수업'은 월 ₩69,000 요금제에 있습니다.
- **서버·계정·구독이 없습니다.** 운영비가 0원이고 기록은 기기 밖으로 나가지 않습니다.

**구조적인 약점 (웹앱이라 생기는 한계)**
- CarPlay와 Android Auto에 연결할 수 없습니다.
- 화면이 꺼지거나 Safari가 뒤로 가면 수업이 멈춥니다.
- 푸시 알림이 없습니다.
- 홈 화면 앱으로 열면 음성 인식이 안 된다는 보고가 있습니다([WebKit 버그 225298](https://bugs.webkit.org/show_bug.cgi?id=225298)).

Pimsleur와 ChatGPT의 차량 경험과 정면으로 겨루려면 결국 네이티브 앱이 필요합니다(4장 1번).

## 3. 이번에 바로 고친 것 (무료, 코드만)

| # | 부족했던 점 | 고친 내용 |
|---|---|---|
| 1 | 백업을 복사할 수만 있고 **복원할 방법이 없었음** | 기록 탭에서 붙여 넣기나 파일 선택으로 복원합니다. 백업 모양이 아니면 거부하고, 두 번 눌러야 덮어씁니다. AI 키는 건드리지 않습니다 (`parseBackup`). |
| 2 | 백업을 파일로 남길 수 없었음 | "백업 파일로 저장"을 추가했습니다(.json, iPhone 파일 앱에 저장). Safari 데이터가 지워지면 기록도 사라진다는 안내도 넣었습니다. |
| 3 | 연속 학습일이 없었음 (경쟁 앱은 모두 리텐션 장치가 있음) | 기록 탭 맨 앞에 "연속 학습 N일 · 수업한 날 모두 N일"을 보여 줍니다 (`streak`). |
| 4 | 알림이 없었음 (웹앱은 푸시 불가) | 수업 화면에 "매일 알림 → 캘린더에 추가"를 넣었습니다. 정한 시각에 매일 반복하는 캘린더 일정(.ics)을 내려받습니다. |
| 5 | 운전 안전 안내가 없었음 | 첫 화면에 안내를 넣었습니다: 출발 전에 시작하고, 주행 중에는 화면을 보거나 만지지 말고, 대답하지 않아도 되며, 두 번 조용하면 저절로 멈춥니다. |
| 6 | 개인정보·데이터 안내가 없었음 | `privacy.html`을 추가했습니다. 기기 저장, Apple 음성 인식, 키가 있을 때만 Anthropic·Google로 전송, 분석 도구 없음을 사실대로 적었습니다. 화면 아래에 링크가 있습니다. |
| 7 | 홈 화면 앱으로 열면 음성 인식이 안 될 수 있음 | 홈 화면 앱으로 열린 경우를 감지해 "Safari에서 직접 여세요"라고 안내합니다. 홈 화면 전용 설정(manifest)은 이 문제 때문에 **일부러 넣지 않았습니다**. |
| 8 | 키를 브라우저에 두는데 보안 정책이 없었음 | CSP를 넣었습니다. 연결은 Anthropic·Google API로만 하고, 리퍼러는 보내지 않습니다. 페이지에 몰래 들어온 코드가 있어도 키를 다른 곳으로 보낼 수 없습니다. |
| 9 | 링크를 공유해도 설명·미리보기가 없었음 | 설명 메타와 OG(제목·설명·그림)를 넣었습니다. |
| 10 | 스크린리더가 진행 상황을 읽지 못했음 | 선생님 말, 상태 칩, 운전 모드 상태에 `aria-live`/`role=status`를 붙였습니다. |
| 11 | README에 이미 만든 기능이 "미구현"으로 남아 있었음 | README와 HANDOFF를 고쳤습니다. |

테스트: 로직 테스트 28개 통과(연속 학습일과 백업 복원 테스트 2개 추가). e2e 통과(복원 거부, 두 번 눌러 확인, 키 보존, 연속 학습일 표시를 추가로 확인).

## 4. 사람이 정할 것

각 항목에 추천을 적었습니다. **굵은 글씨**가 추천입니다.

1. **네이티브 앱 여부** (CarPlay, 백그라운드 오디오, 잠금 화면, 푸시)
   - 웹앱의 가장 큰 한계입니다.
   - 선택지: (a) 계속 웹앱, (b) Capacitor 래퍼(개발자 계정 연 $99, 심사 필요), (c) Swift 네이티브.
   - **본인만 쓴다면 (a)를 유지하세요. 다른 사람에게 출시할 때 (b)를 하세요.**
2. **AI 키 방식**
   - 지금은 사용자가 자기 키를 넣습니다. 일반 사용자에게는 진입 장벽이 너무 높습니다.
   - 출시하려면 서버(Vercel 함수 등)에 키를 두고 사용량 제한·요금 정책을 정해야 합니다. 비용과 악용 방지가 걸려 있습니다.
   - **베타 전까지는 지금 방식을 유지하세요.**
3. **수익 모델**: 무료, 후원, 구독 중에서 정해야 합니다. 스픽은 월 ₩29,000, Pimsleur는 월 약 $20입니다. 서버를 붙이면 AI 비용이 생기므로 2번과 함께 정해야 합니다.
4. **법적 문서**
   - `privacy.html`은 사실을 정리한 초안입니다.
   - 다른 사람에게 공개하려면 운영자 이름과 연락처, 이용약관, 운전 중 사용에 대한 면책을 넣어야 합니다. 한국 도로교통법상 운전 중 휴대전화 사용 제한에 맞는지 검토도 필요합니다.
   - 법률 검토 여부는 사람이 정해야 합니다.
5. **라이선스**: 저장소가 공개인데 LICENSE 파일이 없어서, 지금은 다른 사람이 쓸 권리가 없는 상태입니다. MIT로 열지, 소스만 공개하고 권리는 보유할지 정해야 합니다.
6. **비상 정지** (화면을 길게 누르면 일시정지): "수업 중 음성만" 원칙의 예외라 이전부터 결정을 기다리는 항목입니다. **넣는 쪽을 추천합니다.** 다른 사람이 쓰면 음성 인식 실패가 더 흔해집니다.
7. **홈 화면 앱 설정**: 5장의 확인 결과를 보고 정합니다.
   - 홈 화면 앱에서 음성 인식이 안 되면 `apple-mobile-web-app-capable`을 빼서 아이콘이 Safari 탭으로 열리게 하세요.
   - 되면 홈 화면 앱 설정(manifest)을 추가하세요.
8. **콘텐츠 범위와 레벨**
   - 지금은 출근 12문장과 회화 샘플 102개입니다. 스픽은 레슨이 약 2,000개입니다.
   - 다른 사람에게 출시하려면 레벨 테스트(말로 3문항)와 생활 루틴 선택(출근, 점심, 운동 등)이 있는 온보딩, 레벨별 문장 묶음이 필요합니다.
   - 문장 품질은 사람이 검수해야 해서 시간이 듭니다. 앞서 기다리던 "회화 샘플 다듬기"도 여기에 포함됩니다.
9. **발음 점수**: 지금은 "미측정"입니다. 음소 단위 점수(ELSA 수준)를 내려면 Azure 발음 평가 같은 유료 API와 서버가 필요합니다. **지금처럼 미측정으로 두세요.**
10. **고품질 음성(클라우드 TTS)**: iPhone 프리미엄 음성으로 부족할 때만 하세요. 비용과 서버가 필요합니다.
11. **사용 데이터 수집**: 차 안에서 어디서 실패하는지 알려면 오류 기록이 필요합니다.
    - 기기 안에만 남기는 로그는 무료로 만들 수 있습니다.
    - 서버로 보내면 개인정보 안내도 바꿔야 합니다. 원하는지 정해야 합니다.
12. **오프라인(서비스 워커)**: 만들 수는 있습니다. 하지만 iPhone 음성 인식은 네트워크가 필요할 수 있어 효과가 작고, 캐시 때문에 업데이트가 늦게 반영되는 위험이 있습니다. **5장에서 오프라인 인식을 확인한 뒤에 정하세요.**
13. **Google Fonts**: 접속 정보가 Google로 갑니다. 출시하면 글꼴을 저장소에 직접 넣는 쪽이 낫지만 용량이 늘어납니다. 사소한 문제입니다.

## 5. 실제 iPhone에서 확인할 것

- [ ] 홈 화면 아이콘으로 열었을 때 음성 인식이 되는지 (→ 4장 7번)
- [ ] "백업 파일로 저장"이 파일 앱으로, "캘린더에 추가"가 캘린더로 넘어가는지
- [ ] 비행기 모드에서 en-US 음성 인식이 되는지 (→ 4장 12번)
- [ ] 화면이 잠기면 수업이 어떻게 되는지 (화면 꺼짐 방지가 차량 거치대에서 유지되는지)
- [ ] 이전부터 남은 확인 항목: 새 듣기 방식(긴 답이 끊기지 않는지), 실제 Claude·Gemini 키, 고품질 음성, 한국어 인식
