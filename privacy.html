개인정보·데이터 안내

Commute Coach는 개인이 만든 무료 학습 도구입니다. 회원 가입이 없고, 운영자 서버가 없습니다. 최종 수정: 2026-10-16

기기에 저장되는 것

학습 기록(문장별 단계, 말한 문장, 수업 기록, 내 이야기, 설정)은 이 iPhone의 Safari 저장소(localStorage)에만 저장됩니다. 운영자는 이 기록을 볼 수 없습니다. 기록 탭의 "기록 초기화"로 언제든 지울 수 있고, Safari 방문 기록·웹사이트 데이터를 지워도 사라집니다.

음성

말한 내용은 브라우저의 음성 인식 기능(iPhone에서는 Apple의 음성 인식)으로 글자로 바뀝니다. 이 과정에서 음성이 Apple로 전송될 수 있으며, Apple의 개인정보 처리방침이 적용됩니다. 앱은 녹음 파일을 만들거나 저장하지 않고, 인식된 글자만 기기에 남깁니다.

AI 연결 (선택)

"오늘 이야기 레슨"을 쓰려고 직접 API 키를 넣은 경우에만, 인터뷰 답(글자)이 그 키의 회사로 바로 전송됩니다: Anthropic(Claude) 또는 Google(Gemini). 운영자 서버를 거치지 않습니다. 각 회사의 API 이용 약관과 개인정보 처리방침이 적용되며, 사용 요금은 키 주인에게 청구됩니다. 키는 기기에만 저장되고 백업에 들어가지 않습니다.

그 밖의 외부 연결

글꼴을 Google Fonts에서 불러옵니다(이때 접속 정보가 Google에 전달될 수 있습니다). 페이지는 GitHub Pages에서 제공됩니다. 광고, 분석 도구, 쿠키 추적은 쓰지 않습니다.

운전 안전

수업은 화면을 보지 않고 말로만 하도록 만들었지만, 운전 중 휴대전화 사용에 관한 법규와 안전이 언제나 우선입니다. 출발 전에 시작하고, 주행 중에는 화면을 보거나 만지지 마세요. 집중이 필요할 때는 대답하지 않아도 되며, 두 번 조용하면 수업이 저절로 멈춥니다.
